Don't throw away old computers

Installing Software

Most Linux distributions use a thing called a "Package Manager" which basically means you can install software with a single command via the terminal, for example on Arch you can use the Pacman package manager, on OpenSUSE you can use ZYPPER, on Debian you can use APT, on Void you can use XBPS

Package managers make installing software easier & faster
